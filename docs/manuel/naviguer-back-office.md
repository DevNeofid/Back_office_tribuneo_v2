# Naviguer dans le back-office

## Objectif

Retrouver un écran depuis l'espace de gestion déjà ouvert. Le menu latéral
affiche les entrées suivantes, dans cet ordre.

| Menu | Écran ouvert et usage |
| --- | --- |
| **Accueil** | **Tableau de bord** : raccourcis vers les commandes, partenaires et clients. |
| **Clients** | **Liste des clients** : rechercher et consulter les fiches clients. |
| **Commandes** | **Liste des commandes** : rechercher une commande et accéder à sa gestion. |
| **Partenaires** | **Liste des magasins partenaires** : consulter les partenaires et leurs informations. |
| **Secteurs** | **Secteurs d'activité** : catalogue des secteurs, ajout et suppression. |
| **Documents** | **Documents** : accès aux documents de facturation, dont les frais de gestion. |
| **Virements** | **Historique d'ordres de virement bancaire** : ordres déjà générés. |
| **Prochain virement** | **Prochain virement** : aperçu des demandes à payer ou écartées. |
| **Écritures** | **Écritures comptables** : génération et historique comptables. |
| **Statistiques** | **Statistiques** : rapports et exports statistiques. |

## Étapes

1. Cliquez sur le libellé du menu souhaité. Sur un affichage étroit, ouvrez
   d'abord le menu avec l'icône à trois traits en haut à gauche.
2. Contrôlez le titre de l'écran pour vous repérer. Le menu sélectionné est mis
   en évidence.
3. Pour retrouver les raccourcis, cliquez sur **Accueil**. Le dernier menu
   consulté peut être mémorisé entre deux ouvertures de l'espace de gestion.

Le nom du réseau et l'icône de personne, en haut à droite, ouvrent un menu
contenant **Déconnexion**. Ils ne donnent pas accès à un formulaire de
configuration du réseau dans la version vérifiée.

## Repères et limites

La pastille rouge de **Prochain virement** signale des demandes prêtes à payer
selon l'aperçu ; elle n'atteste aucun paiement bancaire exécuté. Voir
[Comprendre le tableau de bord](comprendre-tableau-bord.md).

Pour une tâche précise, utilisez la fiche correspondante :
[rechercher un client](rechercher-client.md),
[rechercher une commande](rechercher-commande.md),
[consulter un partenaire](rechercher-consulter-partenaire.md),
[consulter les demandes de remboursement](consulter-demandes-remboursement.md)
ou [les ordres de virement existants](consulter-retelecharger-ordre-virement.md).
Les rapports et exports statistiques sont décrits dans
[Consulter et exporter les statistiques](consulter-exporter-statistiques.md).

Aucun menu général **Configuration** ni **Comptes bancaires du réseau** n'est
présent dans le menu actif lu. Voir
[Comprendre la configuration du réseau](comprendre-configuration-reseau.md).

et ne réalise aucune opération de gestion pour vous.
